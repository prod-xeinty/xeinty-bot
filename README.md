# XEINTY Mini App

Прототип Telegram Mini App для битмейкеров. Интерфейс содержит библиотеку демо-битов, карточку бита, форму нового черновика, редактирование текстов для Telegram и YouTube, ключевые слова и ссылки на публикации.

## Запуск

```bash
npm ci
npm run dev
```

Проверка сборки и интерфейса:

```bash
npm run build
node scripts/visual-qa.mjs
npm run test:video
npm run test:persistence
```

Визуальная проверка использует установленный Chrome и делает снимки при ширине 320, 390 и 1440 px в `docs/design/`. Команда также проверяет переходы, редактирование текста и создание черновика.

## Текущие ограничения

- Демо-биты не содержат реального аудио.
- Новые биты, файлы, тексты и ссылки сохраняются в IndexedDB на текущем устройстве и восстанавливаются после закрытия Mini App. Между телефоном и компьютером они не синхронизируются; очистка данных Telegram или браузера может удалить локальные черновики. Готовые MP4 постоянно не хранятся.
- Пробная сборка MP4 из обложки и MP3/WAV работает на устройстве, без сервера. Создай новый бит с обоими файлами и нажми «Собрать MP4» во вкладке «Публикация». Движок загружается при первом запуске (около 31 МБ). После сборки кнопка «Сохранить MP4» открывает выбор папки на компьютере или системное меню отправки файла на телефоне; на iPhone в этом меню нужно выбрать «Сохранить в Файлы». «Обычная загрузка» остаётся запасным способом. Результат доступен только до закрытия страницы.
- Сборка проверена в настольном Chrome на коротком тестовом WAV. Пользователь подтвердил сборку реального бита 1:12 за 15 с и сохранение MP4 в Telegram Desktop; на iPhone подтверждено сохранение через системное меню «Файлы». Большие WAV и Android ещё не проверены.
- Публикация в Telegram/YouTube и статистика ещё не подключены.
- Токен Telegram-бота нельзя помещать в клиентский проект. Для будущего хранения данных и действий от имени пользователя понадобится серверная проверка Telegram `initData`.
