# XEINTY Mini App

Прототип Telegram Mini App для битмейкеров. Интерфейс содержит библиотеку демо-битов, карточку бита, форму нового черновика, редактирование текстов для Telegram и YouTube, ключевые слова и ссылки на публикации.

## Запуск

```bash
npm ci
npm run dev
```

Проверка сборки и интерфейса:

```bash
npm run build
node scripts/visual-qa.mjs
npm run test:video
```

Визуальная проверка использует установленный Chrome и делает снимки при ширине 320, 390 и 1440 px в `docs/design/`. Команда также проверяет переходы, редактирование текста и создание черновика.

## Текущие ограничения

- Демо-биты не содержат реального аудио.
- Новые черновики, тексты и ссылки хранятся только в памяти открытой страницы. Файлы можно прослушать и посмотреть в этой сессии, но после закрытия они исчезнут.
- Пробная сборка MP4 из обложки и MP3/WAV работает на устройстве, без сервера. Создай новый бит с обоими файлами и нажми «Собрать MP4» во вкладке «Публикация». Движок загружается при первом запуске (около 31 МБ). После сборки кнопка «Сохранить MP4» открывает выбор папки, если встроенный браузер поддерживает системный диалог; «Обычная загрузка» остаётся запасным способом. Результат доступен только до закрытия страницы.
- Сборка проверена в настольном Chrome на коротком тестовом WAV. В Telegram Desktop сборка реального бита 1:12 заняла 15 с, но обычная загрузка не сработала; новый системный диалог сохранения ещё нужно проверить в этом клиенте. Сборка и сохранение внутри Telegram на Android и iPhone также требуют проверки: большой WAV может упереться в память устройства.
- Публикация в Telegram/YouTube и статистика ещё не подключены.
- Токен Telegram-бота нельзя помещать в клиентский проект. Для будущего хранения данных и действий от имени пользователя понадобится серверная проверка Telegram `initData`.
