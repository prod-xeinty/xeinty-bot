# Beatsy Mini App

Первый каркас Telegram Mini App для битмейкеров. Сейчас это статическая оболочка: Telegram WebApp запускается, передаёт тему и имя пользователя. Хранения битов и публикации пока нет.

## Локально

```bash
npm install
npm run dev
```

Откройте адрес, показанный Vite. В обычном браузере приложение работает в режиме предпросмотра.

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Как открыть внутри Telegram

Telegram Mini App требует публичный HTTPS-адрес. Бесплатный вариант — GitHub Pages: создать публичный репозиторий, загрузить проект в ветку `main`, в настройках репозитория открыть **Settings → Pages** и выбрать **GitHub Actions**. Готовый workflow `.github/workflows/deploy.yml` соберёт и опубликует приложение по адресу вида `https://USER.github.io/REPO/`. Путь к ресурсам он задаёт автоматически.

После появления HTTPS-адреса: в [@BotFather](https://t.me/BotFather) создать бота (`/newbot`) или выбрать существующего (`/mybots`), открыть **Bot Settings → Configure Mini App → Enable Mini App** и указать HTTPS-адрес. Затем открыть бота в Telegram и нажать кнопку Mini App. Точный набор пунктов BotFather может меняться.

Не вставляйте токен бота в Vite-проект: всё, что попадает в клиентскую сборку, доступно пользователям. `initDataUnsafe` здесь используется только для отображения имени, не для авторизации. Перед хранением личных данных или публикацией от имени пользователя понадобится серверная проверка `initData`.
